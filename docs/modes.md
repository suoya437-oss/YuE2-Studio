# YuE2 三种生成模式详解

三种模式的本质区别：**你给模型的自由度和控制权怎么分配**——从完全放手到精确控制每个音符。

## 1️⃣ 智能创作（cot="full"）——默认推荐

**原理**：先生成完整乐谱规划（ABC 记谱的旋律+和弦），再按谱渲染成歌。

**得到**：完整歌曲 + 一份可读可改的乐谱（score.abc）。

**核心玩法——改谱重渲染**：
1. 复制结果区的 ABC 乐谱 → 贴到「自定义 ABC 乐谱」面板 → 勾选启用；
2. 修改想改的音符/和弦（如把某句 `CDEF` 改 `EFGA`）；
3. 重新生成 → 其余一致，只有你改的地方变了。

适合精细打磨：副歌不好听？只改那几个音重跑。
耗时约 2–3 分钟/首；官方基准测试用此模式，综合质量最高。

## 2️⃣ 翻唱改编（cot="melody"）——锁旋律、自由编曲

**原理**：旋律被乐谱锁死（一个音都不变），和弦与伴奏完全自由，按新风格即兴配。

**两种用法**：

| 用法 | 操作 |
|------|------|
| AI 翻唱（完整链路） | 「翻唱」面板上传原曲 → 自动转录 ABC → 填新歌词/风格/人声 → 生成 |
| 旋律重生 | 任何现成 ABC 贴进乐谱框 → 换风格生成，同旋律多版本对比 |

**风格写狠一点效果才明显**（旋律不变，风格是最大变量）：
如 `80s synth-pop, analog synths, drum machine, 118 BPM`。
翻唱时 BPM 尽量接近原曲，差太多会有节奏拉伸怪感。

**注意**：转录质量决定翻唱质量，重要曲目值得人工核对乐谱。

## 3️⃣ 快速直出（cot="off"）——跳过规划

**原理**：不做乐谱规划，歌词直接生成音频。

最快最省事，适合试词听效果；但没有乐谱环节，不满意只能换种子碰运气，不能"改两个音重跑"。与自定义乐谱互斥。

## 📊 怎么选

| 你想做的事 | 选 |
|-----------|---|
| 随便写词出一首歌 | 快速直出 |
| 认真创作、反复打磨 | 智能创作 |
| 翻唱/改编现成的歌 | 翻唱改编 |
| 拿不准 | 智能创作（默认） |

## 风格对各模式的影响

| 模式 | 影响旋律 | 影响什么 |
|------|---------|---------|
| 快速直出 | ✅ | 一切 |
| 智能创作 | ✅ | 作曲（旋律走向/和弦进行）+ 编曲演唱 |
| 翻唱改编 | ❌ 音符锁死 | 伴奏、和声、音色、演唱处理（翻唱原理所在） |

## 通用技巧

- 风格串权重从前往后递减：语言 → 人声 → 曲风 → 乐器 → 速度
- 人声用英文标签（deep male baritone vocals 等）识别最稳
- 满意的歌记下种子数字，同种子+同请求=复现
- 出错先换种子再改参数
